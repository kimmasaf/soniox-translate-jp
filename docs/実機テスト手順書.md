# Soniox 翻訳 — Even G2 実機テスト手順書

このアプリを手元の PC から Even G2 実機で動かす手順です。
方法は 2 つあります。普段の確認は **A. ローカルテスト**、配布用パッケージの確認は **B. プライベートビルド** を使います。

| | A. ローカルテスト(QR 読み込み) | B. プライベートビルド(.ehpk) |
|---|---|---|
| 用途 | 動作確認・表示の調整(毎回これ) | 本番と同じパッケージでの確認 |
| 変更の反映 | 保存すると約 1 秒で反映 | ビルド → アップロード → インストールし直し |
| PC と同じ Wi-Fi | 必要 | 不要 |
| スマホをロックすると | 止まる(QR を読み直す) | しばらくは動く |

参考: 公式ドキュメント [Test](https://hub.evenrealities.com/docs/test)、[Local Testing](https://hub.evenrealities.com/docs/test/local-testing)、[Private Testing](https://hub.evenrealities.com/docs/test/private-testing)

## 0. 事前準備(初回だけ)

### 0-1. スマホとメガネ

1. スマホに **Even Realities アプリ** を入れ、アカウントを登録します。
   **バージョン 2.2.10 以上**が必要です(このアプリが使う SDK 0.0.16 の最低条件)。
2. G2 をアプリとペアリングし、ファームウェア更新が出たら先に済ませます。
3. **開発者モードを有効にする**
   1. PC のブラウザで [hub.evenrealities.com](https://hub.evenrealities.com/login) に、スマホと同じアカウントでログイン
   2. スマホの Even Realities アプリを完全に終了して開き直す
   3. 「Even Hub」タブの右上に開発者用の項目(QR スキャン)が出れば OK

### 0-2. PC

1. **Node.js 20 以上**(22 LTS 推奨)をインストール
   - Mac: `brew install node@22`、または [nodejs.org](https://nodejs.org/) のインストーラー
   - Windows: `winget install OpenJS.NodeJS.LTS`
   - 確認: `node -v` が `v20` 以上
2. **ソースを取得**

   ```bash
   git clone https://github.com/kimmasaf/soniox-translate-jp.git
   cd soniox-translate-jp
   npm install
   ```

   SDK・CLI・シミュレーターはこのプロジェクトの依存に入っているので、別途グローバルに入れる必要はありません(`npx evenhub ...` で使えます)。

3. **Soniox の API キー**を用意します([console.soniox.com](https://console.soniox.com) で取得)。
   キーの入れ方は 2 通りあります。**基本は②(アプリの設定画面で入力)を推奨**します。

   | 方法 | 手順 | 注意 |
   |---|---|---|
   | ① 開発用ファイル | `.env.local` に `VITE_STT_API_KEY=<キー>` | 開発サーバーが配信する JS にキーが埋め込まれ、**同じネットワークの誰でも取得できます**。自宅 Wi-Fi やスマホのテザリングなど、信頼できるネットワークでだけ使ってください |
   | ② アプリの設定画面 | 実機で起動後、スマホ画面の「⚙︎ 設定」→「API キー」に貼り付けて「保存」 | キーはそのスマホ内にだけ保存されます。会社や公共の Wi-Fi ではこちら |

## A. ローカルテスト(QR で読み込み) — 普段の確認はこれ

PC で開発サーバーを動かし、スマホの Even アプリが QR 経由で読み込みます。

### A-1. PC の LAN 内 IP アドレスを調べる

- Mac: `ipconfig getifaddr en0`(Wi-Fi の場合)
- Windows: `ipconfig` → 「Wi-Fi」の「IPv4 アドレス」

以下、例として `192.168.1.23` とします。

### A-2. 開発サーバーを起動する(ターミナル 1)

```bash
npx vite --host 192.168.1.23 --port 5173
```

- `--host` にはその IP を指定します。`npm run dev` でも動きますが、こちらは全インターフェースで待ち受けるため、IP を指定する方が公開範囲が狭く安全です。
- `Network: http://192.168.1.23:5173/` と表示されれば OK。
- 初回は OS のファイアウォールが「受信を許可するか」を聞いてくるので、**プライベートネットワークのみ許可**してください。

### A-3. QR を表示する(ターミナル 2)

```bash
npx evenhub qr --url "http://192.168.1.23:5173"
```

### A-4. スマホで読み込む

1. Even Realities アプリ → 「Even Hub」タブ → 右上の開発者メニュー → **Scan QR**
2. ターミナルの QR を読み取る
3. 1 秒ほどでメガネに表示され、スマホにはアプリ画面(翻訳/原文、⚙︎ 設定)が出ます

### A-5. 動作確認チェックリスト

| # | 確認すること | 期待する結果 |
|---|---|---|
| 1 | スマホ画面 | 日本語表示、文字が大きい。「⚙︎ 設定」で設定画面、「‹ 戻る」で戻る |
| 2 | 翻訳先 = 日本語のまま、英語で話す | メガネの上段に英語の原文、下段に日本語訳 |
| 3 | 日本語で話す | 日本語は**下段に 1 回だけ**表示(上段に同じ文は出ない) |
| 4 | 設定 →「話者を識別」をオン → 保存し、2 人で話す | スマホには「話者1」「話者2」のラベル。**メガネにはラベルなし**(話者が替わると改行のみ) |
| 5 | 設定 →「表示モード」を切り替えて保存 | 上下分割(原文 2 行)/上下分割(原文 3:翻訳 7)/対訳(原文の次の行に「→ 翻訳」)/翻訳のみ。スマホ画面も同じモードになる |
| 6 | テンプルをダブルタップ | 終了確認が出て、アプリが終了する |
| 7 | もう一度起動 → スマホの「履歴」 | 前回の会話が対訳の形で残っている。「書き出す」でテキストファイルを保存・共有でき、うまくいかないときは「コピー」でも取り出せる |

### A-6. うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| QR を読んでも「接続できない」 | PC のファイアウォールがポート 5173 の受信を止めている。許可する |
| 読んでも何も起きない | Wi-Fi の「AP 分離(クライアント分離)」で端末同士が通信できない。会社 Wi-Fi に多い → **スマホのテザリングに PC をつなぐ**のが手軽 |
| 一度動いたが、スマホをロックしたら真っ白 | ローカルテストの仕様。QR を読み直す |
| 「要設定: …API キー」と出る | 0-2 の手順 3 のどちらかでキーを入れる |
| 「エラー: 音声認識: Soniox 401 …」 | API キーの誤り。設定画面で入れ直す |
| 編集しても反映されない | QR を読み直す(ページを全部読み込み直す) |

コードを編集して保存すると、メガネとスマホの表示が自動で更新されます。

## B. プライベートビルド(本番と同じ .ehpk) — 配布前の確認

本番と同じパッケージ形式で自分のメガネにだけインストールします。PC とスマホが同じ Wi-Fi にいる必要はありません。

### B-1. ログインと package_id(済み)

`package_id` は `com.kimmasaf.sonioxtranslatejp` に変更し、このアカウントでアプリを作成済みです(2026-11-22、ビルド 0.1.0)。
別の PC から操作する場合は、最初にログインだけ行います。

```bash
npx evenhub login          # Even Realities アカウントでログイン(パスワード入力あり)
npx evenhub self-check     # ログイン中のアカウントを確認
npx evenhub ls             # com.kimmasaf.sonioxtranslatejp が出れば OK
```

`package_id` のルール: 小文字の英数字だけ、各区切りは英字で始まる、2 区切り以上、ハイフン不可。全体で一意である必要があります。

### B-2. ビルドしてパッケージを作る

```bash
npm run build
npx evenhub pack app.json dist -o soniox-translate.ehpk
```

- 本番ビルドには `.env.local` のキーは**入りません**。インストール後、アプリの設定画面でキーを入力します。
- 念のため `grep -r "<キーの先頭数文字>" dist` で何も出ないことを確認できます。

### B-3. アップロード

**初回**(アプリを新規作成。このアプリは作成済みなので不要):

```bash
npx evenhub create soniox-translate.ehpk --name "Soniox 翻訳" --tagline "リアルタイム翻訳字幕"
```

**2 回目以降**は、`app.json` の `version` を上げて(例 `0.1.0` → `0.1.1`)B-2 をやり直し、次を実行します。

```bash
npx evenhub upload soniox-translate.ehpk -m "変更内容のメモ"
```

Web の [hub.evenrealities.com](https://hub.evenrealities.com/login) → プロジェクト → Builds からアップロードしても同じです。

### B-4. スマホにインストールして起動

1. Even Realities アプリの **Me → Apps → Private builds**(公式ドキュメントの表記)
   - 「Me」は Even Hub タブの中ではなく、アプリ画面下の別タブ(プロフィール)と思われます
   - 見つからないときは、アプリを完全に終了して開き直す/アップロードしたアカウントでログインしているか/アプリが 2.2.10 以上かを確認
   - それでも出ない場合はベータ配布(下記)に切り替え、**Me → Beta tester** からインストール
2. アップロードしたビルドの **Install** をタップ
3. 同じ画面から起動します(プライベートビルドはメガネのメニューには出ません。スマホから起動します)
4. 初回はマイクの許可を求められるので許可
5. スマホ画面の「⚙︎ 設定」で API キーを入れて「保存」→ A-5 のチェックリストで確認

メガネのメニューから起動したい、または他の人にも試してもらいたい場合は、ベータ配布(`npx evenhub promote <version> --to beta`)を使います([Beta Testing](https://hub.evenrealities.com/docs/test))。

## 参考: 実機を使わない確認(Linux 開発環境)

この開発環境では、シミュレーターをコンテナで動かし、テスト音声を仮想マイクに流して確認できます。

```bash
sim/run.sh                                                  # 起動してスクショ
AUDIO=/app/test-audio/dialog.wav SPEAKERS=1 sim/run.sh      # 2 人の会話(日本語+英語)を流す
AUDIO=/app/test-audio/en.wav sim/run.sh                     # 英語 → 日本語
node scripts/make-test-audio.mjs                            # テスト音声を作り直す(Soniox TTS)
```

結果は `sim/out/` に保存されます。シミュレーターは表示とロジックの確認用です。音声の遅延や Bluetooth の挙動は、必ず実機で確認してください。
